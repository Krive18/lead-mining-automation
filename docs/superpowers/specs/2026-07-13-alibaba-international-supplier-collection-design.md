# 阿里巴巴国际站广东供应商采集设计

## 1. 目标

新增独立采集方向“阿里国际站采集”。用户输入产品关键词后，系统在 Alibaba.com 供应商搜索列表页提取供应商公开信息，仅保留广东省供应商并写入线索库。

本阶段仅采集和保存，不自动调用启信宝，不进入供应商详情页。

## 2. 范围

### 2.1 包含

- 新增来源类型 `alibaba_international` 和前端采集入口。
- 按用户输入的产品关键词进入 Alibaba.com `All suppliers` 结果。
- 从供应商卡片提取英文公司名、主营产品小类目、店铺等级原文、平台地区和供应商主页。
- 仅保留明确属于广东省的供应商。
- 新字段贯通数据库、API、线索库和 Excel 导出。
- 任务日志展示搜索词、解析卡片数、广东通过数、过滤数和入库数。

### 2.2 不包含

- 不进入供应商详情页。
- 不提取营业执照 `Registration No.`。
- 不提取法人、股东或电话。
- 不在任务完成后自动跳转或调用启信宝。
- 不将店铺徽标自行转换为中文等级。

## 3. 用户流程

1. 用户在任务中心选择“阿里国际站采集”。
2. 选择行业或“其他”，输入一个或多个产品关键词和采集数量。
3. 系统依次搜索关键词，加载供应商列表页可见卡片。
4. 系统解析卡片并执行广东地区过滤、关键词相关性过滤和去重。
5. 合格数据写入线索库，任务完成后可查看和导出。

## 4. 数据字段

| 业务字段 | 存储字段 | 规则 |
| --- | --- | --- |
| 英文公司名称 | `company_name_en` | 保留页面原文，同时作为本来源的公司显示名和去重主键之一 |
| 主营产品小类目 | `product_name` | 保留卡片 `Main products` 或等价可见文本，多项用中文分号连接 |
| 店铺等级原文 | `shop_level` | 保留平台徽标原文，多项用英文分号连接，例如 `Verified Supplier; Custom Manufacturer` |
| 供应商主页 | `shop_url` / `profile_url` | 保存卡片中供应商主页链接，不保存商品详情链接 |
| 搜索关键词 | `source_keyword` | 保存该卡片所属的原始产品搜索词 |
| 来源类型 | `source_type` | 固定为 `alibaba_international` |
| 省/市 | `province` / `city` | 省固定为已验证的“广东”；市仅在卡片明确显示广东城市时写入 |

`company_name_en` 和 `shop_level` 需新增数据库列、迁移逻辑、后端 DTO/API 字段、前端展示和 Excel 导出列，保证完整字段链路。

## 5. 采集器设计

新建独立 `AlibabaInternationalSupplierCollector`，复用现有 Playwright 启动、任务日志、抖动等待和停止任务机制，但不复用 1688 中文公司名解析规则。

每张供应商卡片按如下顺序处理：

1. 识别英文公司名和供应商主页。
2. 识别平台地区文本。
3. 仅在地区包含 `Guangdong` 或可确认的广东城市时继续。
4. 从 `Main products` 及公司名附近的产品摘要提取小类目。
5. 从可见徽标文本中提取店铺等级原文。
6. 用规范化英文公司名和供应商主页去重。

采集器不将 `Trade Assurance`、`ODM service available`、评分、年限或响应率误认为店铺等级。等级只接受经白名单确认的平台供应商徽标，初始包含 `Verified Supplier`、`Gold Supplier`、`Custom Manufacturer`、`Multispecialty Supplier` 和页面实际出现的同类官方标识。

## 6. 关键词和广东过滤

- 搜索词使用用户输入原文，不自动追加 `factory`、`manufacturer` 或其他限定词。
- 多关键词依次搜索，采集数量在各关键词间尽量均衡。
- 卡片产品文本必须与当前关键词具有直接词面或可接受的归一化匹配，避免跨类目采集。
- 广东城市英文及常见拼写作为广东证据，但只有 `China` 而无省市的卡片不入库。

## 7. 异常与风险处理

- 搜索页出现登录、验证码、访问限制或空白结果时，任务停在可诊断状态并记录具体原因，不用关键词伪造线索。
- 单张卡片缺少英文公司名、地区或主营小类目时跳过该卡片，不影响其他卡片。
- 店铺等级缺失时允许保存为空，不自行填写“普通店铺”。
- 保留已经成功入库的数据；后续页面失败不回滚前序成功线索。

## 8. 界面与导出

- 任务中心采集方向增加“阿里国际站采集”。
- 关键词输入框提示使用产品词，例如 `stage light`、`game controller`、`garment steamer`。
- 显示简短提示：“只采集广东供应商列表页信息，不自动调用启信宝。”
- 线索库显示英文公司名、产品小类目和店铺等级。
- Excel 导出增加“英文公司名称”和“店铺等级”列，供应商主页保存为可点击链接。

## 9. 测试与验收

### 9.1 单元测试

- 中英文广东地区文本能正确通过，非广东地区和地区不明能正确拒绝。
- 供应商卡片能正确提取英文公司名、小类目、店铺等级和主页。
- 服务能力、响应率、年限和关键词本身不会被当作小类目或店铺等级。
- 去重逻辑同时覆盖英文公司名和供应商主页。
- 数据库迁移、仓库读写和 Excel 导出保留新字段。

### 9.2 端到端验收

1. 使用一个产品关键词创建任务。
2. 任务列表显示独立的“阿里国际站”方向和实时进度。
3. 线索库中新增记录都有英文公司名和产品小类目，地区都能明确归属广东。
4. 有平台徽标的卡片按页面原文保存店铺等级，无徽标的卡片等级为空。
5. Excel 导出包含英文公司名称、产品小类目、店铺等级和阿里国际站供应商主页。
6. 任务过程中不调用启信宝。

## 10. 已知限制与后续阶段

- Alibaba.com 页面结构可能调整，采集器需同时使用语义标签、卡片文本和链接特征，并将解析失败原因写入日志。
- 英文公司名不一定能被启信宝精确匹配。后续启信宝验证阶段建议增加国际站供应商详情页 `Registration No.` 提取，但不在本次实施范围内。
