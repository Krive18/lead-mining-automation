1688页面采集书签

新版 2026-06-12-v2：把下面的蓝色按钮拖到浏览器收藏栏。之后在普通 Edge 打开的 1688 搜索结果页、店铺页或详情页点击收藏栏书签，即可把公开可见内容导入本地系统。

1688采集助手
支持模式：
  1. 当前页/详情页采集：读取当前页面公开可见字段；在详情页会尝试点击“电话联系”，只提取公开弹窗中展示的联系人和号码。
  2. 可视化批量翻页采集：在搜索结果页慢速加载后续页，左侧会弹出蓝框预览窗口，方便确认第 2 页、第 3 页等页面是否真的被打开。该模式只读列表可见字段，不进入详情页，所以通常不含联系人和电话。
  3. 边界：不会绕过验证、登录或访问限制；遇到验证、访问被拒绝、读取失败会停止，需要人工处理后再继续。

如果浏览器不允许拖动书签，可复制下面的短脚本，新建收藏夹并粘贴到网址栏。
