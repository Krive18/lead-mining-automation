Automation-AI first-time setup

1. Do not run BAT files inside the ZIP preview window.
2. Right-click Automation-AI.zip and choose "Extract All".
3. Open the extracted Automation-AI folder.
4. Double-click setup_environment.bat or 一键配置环境.bat.
5. After setup finishes, double-click start_project.bat.

首次使用说明：

1. 不要在 ZIP 压缩包预览窗口里直接双击 BAT。
2. 右键 Automation-AI.zip，选择“全部解压”。
3. 进入解压后的 Automation-AI 文件夹。
4. 双击 setup_environment.bat 或“一键配置环境.bat”。
5. 配置成功后，双击 start_project.bat 启动项目。
